### Project Name

**Weather Application** – Real-Time Weather Information System**

### Technologies / Tools Used

**Frontend:** HTML, CSS, JavaScript
**Backend:** Java, Spring Boot
**API:** OpenWeather API
**Development Tools:** VS Code / Eclipse

### Project Description

The **Weather Application** is a web-based application designed to provide users with real-time weather information for a selected location. The application integrates the **OpenWeather API** to retrieve current weather data and uses a **Java Spring Boot backend** to handle API communication and application logic. The retrieved information is processed and presented through a simple, responsive, and user-friendly interface.

### Key Features

* Search and retrieve weather information based on city/location.
* Display real-time temperature and weather conditions.
* Provide additional weather details such as humidity and related information.
* Integrate with the OpenWeather API for live weather data.
* Use Spring Boot for backend processing and API integration.
* Provide an intuitive interface for easy access to weather information.

### Purpose & Real-World Impact

The application provides users with **quick and accessible weather information** that can support everyday decision-making. It can help users plan travel, outdoor activities, work, and other daily activities based on current weather conditions. The project also demonstrates the practical implementation of **REST API integration, backend development, frontend development, and client-server communication**.
